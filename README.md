# FATHOM — a Lusion-style immersive scroll site, built from scratch by Devin

Fictional deep-ocean survey institute. The page *is* the water column: the ground darkens with scroll depth, 20k GPGPU marine-snow particles are pushed by the cursor, a click sends a sonar ring, and a pinned scroll-film descends through five light zones with live depth/pressure/temperature readouts.

Stack: Vite · Three.js (custom GLSL, ping-pong simulation) · GSAP ScrollTrigger · Lenis · self-hosted Bricolage Grotesque + IBM Plex Mono. No stock imagery: expedition charts are procedurally drawn.

```
npm i && npm run dev
```
